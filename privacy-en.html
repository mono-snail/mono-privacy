MonoProxy Privacy Policy

Effective Date: July 2026

Overview

MonoProxy is a local proxy server application that supports HTTP / HTTPS together with SOCKS4 / SOCKS4a / SOCKS5 on the same port. We take your privacy seriously. This privacy policy explains how we handle your data.

Data Collection

Information We Don't Collect

  • ❌ Personal identity information (name, email, phone, etc.)
  • ❌ Device information
  • ❌ Location information
  • ❌ Usage behavior data
  • ❌ Browsing data on our servers

Information We Process

  • ✅ Network traffic data processed locally on device
  • ✅ Temporary runtime statistics (displayed only in app)
  • ✅ User settings (saved only on device locally)
  • ✅ Optional host-only history and site traffic totals, stored locally only when enabled

Data Usage

Local Processing

  • All data is processed only on your device
  • Proxy traffic, credentials, history, and statistics are not uploaded to our servers
  • Data is not shared with third parties except feedback you explicitly choose to submit

Network Functions

  • The proxy service only forwards HTTP / HTTPS and SOCKS4 / SOCKS4a / SOCKS5 requests locally
  • Does not record or store access content
  • Does not analyze network traffic
  • If proxy username/password authentication is enabled, credentials are stored only on the device, never uploaded, and never written to any log
  • HTTPS tunnels are relayed without certificate installation, decryption, or content inspection

Data Security

Local Storage

  • App data is protected by iOS standard security mechanisms
  • Other apps cannot access our data
  • Data is automatically encrypted when device is locked

Network Transmission

  • Uses standard HTTPS/TLS encryption
  • No proxy credentials, browsing history, or proxied content is transmitted to us

Third-Party Services

This app does not use third-party analytics or advertising SDKs. If you voluntarily send feedback, the text you enter, optional email address, app version, and iOS version are submitted to a third-party form service solely to deliver that feedback.

Data Retention

  • Runtime connection data exists only while the app is running
  • When optional browsing history is enabled, host-only records are capped at 500 entries and seven days
  • Optional site traffic totals and app settings remain locally until you clear them or uninstall the app
  • Data in the app container is removed by iOS when the app is uninstalled
  • Users can clear data at any time within the app

Children's Privacy

This app does not collect any personal information, making it suitable for users of all ages.

International Users

This app can be used globally. Data processing is not restricted by geography because all data is processed locally on the user's device.

Your Rights

  • Access Right: You can view all data in the app at any time
  • Deletion Right: You can delete the app or clear data at any time
  • Modification Right: You can change app settings at any time
  • Restriction Right: You can stop using the proxy service at any time
