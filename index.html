Connect your iPhone and Mac in three steps

  1. Start on iPhone

    Keep both devices on the same local network and start the proxy service. Open Connect a Device and select macOS.

  2. Add it on Mac

    In Companion, add the discovered phone service as a configuration. If discovery is unavailable, enter the address and port shown on iPhone.

  3. Connect and verify

    Enter the proxy credentials if required, then connect. Open a page and confirm verified traffic in the iOS app.

You set the proxy credentials

Set this proxy service’s username and password in the iOS app’s authentication settings. When authentication is enabled, enter that same username and password on the device connecting to it.
