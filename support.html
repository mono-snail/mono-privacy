功能概览

  • 在同一端口上同时支持 HTTP / HTTPS 与 SOCKS4 / SOCKS4a / SOCKS5 协议，客户端无需区分
  • SOCKS5 支持可选的账号密码验证
  • 为 iPhone、Android、macOS 和 Windows 客户端提供“连接设备”配置引导
  • 明确区分“正在监听”“客户端已连接”和“流量已验证”
  • 实时上传 / 下载速率与流量统计

配置指南： macOS · Windows

常见问题

Q: 代理无法启动？

A: 请检查端口是否被其他应用占用，尝试更换端口号。

Q: 支持哪些代理协议？

A: 同时支持 HTTP、HTTPS 以及 SOCKS4 / SOCKS4a / SOCKS5。所有协议共用同一个端口，MonoProxy 会自动识别客户端使用的协议。

Q: 如何为 SOCKS5 设置账号密码？

A: 在应用内开启 SOCKS5 验证并填写用户名与密码即可。凭据仅保存在本机，不会上传，也不会出现在任何日志中。若客户端未按要求提供正确凭据，连接将被拒绝。

Q: 如何确认代理是否正常工作？

A: 启动代理后打开“连接设备”，让客户端处于同一 Wi-Fi 或局域网并完成配置。“正在监听”表示服务已就绪，“客户端已连接”表示已有 TCP 客户端接入，只有真实代理数据完成传输后才会显示“流量已验证”。

Q: 连接速度慢？

A: 确保网络连接稳定，可以尝试重启代理服务。

Q: 自然声音无法播放？

A: 检查设备的静音开关和音量设置，然后重新选择雨声、海浪或其他声音。
