MonoProxy
Client setup

Use your iPhone as a local proxy server on Mac

Run MonoProxy on an iPhone or iPad, configure the macOS HTTP, HTTPS, or SOCKS settings, then confirm that real traffic reaches the device.

客户端配置

将 Mac 连接到 MonoProxy

把 MonoProxy 显示的地址同时填入 macOS 的两个 Web 代理开关，然后确认真实流量已经到达 iPhone。

Before you begin
  • Connect the iPhone and Mac to the same Wi-Fi or local network.
  • Start MonoProxy and wait until it shows Listening.
  • Keep the displayed IP address and port available, for example 192.168.1.20:8080.

System proxy setup

1

Open the active network

Open System Settings → Network. Select the Wi-Fi or Ethernet connection currently in use, then choose Details.

2

Open Proxies

Select Proxies in the sidebar.

3

Configure HTTP

Enable Web Proxy (HTTP). Enter the MonoProxy IP in Server and its port in Port.

4

Configure HTTPS

Enable Secure Web Proxy (HTTPS) and enter the same server and port. This separate switch is required for HTTPS websites.

5

Add credentials if enabled

If authentication is enabled in MonoProxy, turn on the password option and enter the same username and password for both proxy entries.

6

Apply and verify

Select OK, then Apply. Open an HTTP and an HTTPS website. MonoProxy should move from Listening to Client Connected and then Traffic Verified.

Do not enable only Web Proxy (HTTP). macOS handles HTTPS through the separate Secure Web Proxy (HTTPS) entry.

Protocol choices

HTTPUse Web Proxy (HTTP).
HTTPSUse Secure Web Proxy (HTTPS).
SOCKSEnable SOCKS Proxy instead when the client specifically needs SOCKS4/5.

When you finish

Return to the same Proxies screen and disable the proxy switches when MonoProxy is no longer running. Otherwise the Mac may appear offline.

开始之前
  • 确保 iPhone 和 Mac 连接到同一个 Wi-Fi 或局域网。
  • 启动 MonoProxy，并等待状态显示为“正在监听”。
  • 记下 App 显示的 IP 和端口，例如 192.168.1.20:8080。

配置系统代理

1

打开当前网络

进入系统设置 → 网络，选择正在使用的 Wi-Fi 或以太网，然后点击详细信息。

2

打开代理设置

在侧边栏选择代理。

3

配置 HTTP

启用 Web 代理 (HTTP)，服务器填写 MonoProxy 的 IP，端口填写 App 显示的端口。

4

配置 HTTPS

启用安全 Web 代理 (HTTPS)，填写相同的服务器和端口。HTTPS 网站必须单独开启这个开关。

5

按需填写凭据

如果 MonoProxy 开启了认证，请在两个代理配置中都启用密码选项，并填写相同的用户名和密码。

6

应用并验证

点击好和应用，分别打开一个 HTTP 与 HTTPS 网站。MonoProxy 应从“正在监听”变为“客户端已连接”，随后显示“流量已验证”。

不要只开启 Web 代理 (HTTP)。macOS 会通过独立的“安全 Web 代理 (HTTPS)”处理 HTTPS 网站。

协议选择

HTTP使用 Web 代理 (HTTP)。
HTTPS使用安全 Web 代理 (HTTPS)。
SOCKS客户端明确需要 SOCKS4/5 时，改为启用 SOCKS 代理。

使用结束后

MonoProxy 停止运行后，请回到同一代理页面关闭相关开关，否则 Mac 可能表现为无法联网。
