MonoProxy
Client setup

Connect Windows to MonoProxy

Use Windows manual proxy settings for HTTP and HTTPS traffic, or configure SOCKS inside an application that supports it.

客户端配置

将 Windows 连接到 MonoProxy

通过 Windows 手动代理设置接入 HTTP 与 HTTPS 流量；需要 SOCKS 时，请在支持 SOCKS 的应用中单独配置。

Before you begin
  • Connect the iPhone and Windows PC to the same Wi-Fi or local network.
  • Start MonoProxy and wait until it shows Listening.
  • Keep the displayed IP address and port available, for example 192.168.1.20:8080.

Windows 11 system proxy

1

Open Proxy settings

Open Settings → Network & internet → Proxy.

2

Open manual setup

Under Manual proxy setup, select Set up next to Use a proxy server.

3

Enter the MonoProxy address

Turn on Use a proxy server. Enter the iPhone IP in Proxy IP address and the MonoProxy port in Port.

4

Save and verify

Select Save, then open an HTTP and an HTTPS website. MonoProxy should move from Listening to Client Connected and then Traffic Verified.

The Windows system proxy covers HTTP and HTTPS. It does not provide a general SOCKS switch.

Using SOCKS4 or SOCKS5

Browser or app settingChoose SOCKS4 or SOCKS5 in an application that supports a custom proxy, then use the same MonoProxy IP and port.
AuthenticationIf MonoProxy authentication is enabled, enter the configured username and password in the client application.

When you finish

Turn off Use a proxy server after MonoProxy stops. Leaving an unavailable manual proxy enabled can make Windows apps appear offline.
开始之前
  • 确保 iPhone 和 Windows 电脑连接到同一个 Wi-Fi 或局域网。
  • 启动 MonoProxy，并等待状态显示为“正在监听”。
  • 记下 App 显示的 IP 和端口，例如 192.168.1.20:8080。

Windows 11 系统代理

1

打开代理设置

进入设置 → 网络和 Internet → 代理。

2

打开手动代理

在手动设置代理下，点击“使用代理服务器”旁边的设置。

3

填写 MonoProxy 地址

开启使用代理服务器，代理 IP 地址填写 iPhone 的 IP，端口填写 MonoProxy 显示的端口。

4

保存并验证

点击保存，分别打开一个 HTTP 与 HTTPS 网站。MonoProxy 应从“正在监听”变为“客户端已连接”，随后显示“流量已验证”。

Windows 系统代理会处理 HTTP 和 HTTPS。该页面没有全局 SOCKS 开关。

使用 SOCKS4 或 SOCKS5

浏览器或应用内设置在支持自定义代理的应用中选择 SOCKS4 或 SOCKS5，并填写相同的 MonoProxy IP 和端口。
认证如果 MonoProxy 开启了认证，请在客户端应用中填写对应的用户名和密码。

使用结束后

MonoProxy 停止运行后，请关闭“使用代理服务器”，否则部分 Windows 应用可能表现为无法联网。
